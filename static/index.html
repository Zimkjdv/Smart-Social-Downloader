安全佇列

個／60 分鐘

預設 40，可設定 1～1000。以最近 60 分鐘啟動的工作計算，失敗與重新下載也會計入。儲存後立即套用，保留目前已用計數。

目前已用 —/40 個工作

確認後將已用計數歸零，後續工作重新累計。每小時上限不變，工作延時與平台冷卻仍會保留。

各平台模式可繼續其他平台的工作；全域 Rate 上限、單 worker 與請求間隔仍共同遵守。切換模式不會清除既有冷卻。

秒

預設 300 秒，可設定 30～3600。長時間沒有傳輸或處理進度時停止該工作；安全佇列等待不計入，持續有進度的長影片不受總耗時限制。下個工作生效。

一般解析找不到來源時，使用隔離暫時 Chrome 執行頁面腳本。預設關閉；不讀取日常 Chrome 登入，不自動登入或點擊頁面按鈕。最多 45 秒、40 個請求。

安裝選配套件： python tools/manage.py browser-setup

X 登入連接

使用平常 Chrome 中已登入的 X。無法直接讀取時，會開啟一般 Chrome 的本機連接頁；第一次載入連接器後，便可一鍵同步並自動重試失敗的 X 項目。

尚未連接 X 登入

Chrome 連接器安裝步驟

只保留 X 登入 Cookie，在這台電腦以 Windows 加密保存。不需要匯出檔案，也不讀取 Google 或 Apple 的登入資料。

X 顯示暫時限制登入時，請停止反覆嘗試，待限制解除後在一般 Chrome 登入。連接器不能解除帳號限制。

進階：使用 Cookie 檔案
◈

支援 Netscape 格式 cookies.txt。如需改用檔案，請先停用 Chrome 連接，再填入完整路徑並儲存。兩者皆未設定時使用公開貼文資料。
