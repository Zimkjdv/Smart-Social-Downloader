載入 Chrome 本機連接器

下載 Chrome 連接器

  1. 開啟擴充功能管理頁

    請使用你平常登入 X 的 Chrome 個人檔案。

  2. 開啟右上角「開發人員模式」
  3. 按「載入未封裝項目」，選擇這個資料夾

    選擇包含 manifest.json 的整個資料夾。連接器名稱為「Smart Social Downloader · X 連接器」。

  4. 回到此頁並重新整理

    已登入 X 時會自動連接；也可以按上方「連接已登入的 X」。

這是 Chrome 官方支援的本機擴充功能載入方式。查看官方步驟 ↗

X 顯示「暫時限制登入」時

先停止反覆登入。X 官方說明，多次登入失敗造成的暫時鎖定通常約一小時後解除；請先確認能在一般 Chrome 正常登入，再使用連接器。此工具不能解除帳號限制。
